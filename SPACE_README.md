# MedVision Edge — Offline Chest X-ray Analysis

AI-powered chest X-ray screening using **Gemma 4 E4B** fine-tuned on ~23K radiographs from NIH ChestX-ray14 (112K-image dataset, with capacity for further scaling).

Detects 5 pathologies validated on NIH ChestX-ray14 and CheXpert gold standard benchmarks.

**Video Demo:** https://youtu.be/VFHtjTz7u2U

See [GitHub repo](https://github.com/J4rias/medvision-edge) for full documentation.
